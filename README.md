# Rubik's Cube 3D

A fully interactive 3D Rubik's Cube built with Three.js.

## Features
- Realistic 3D cube with official Rubik's colors
- Mouse drag / touch to rotate faces
- Keyboard controls (R, L, U, D, F, B + Shift for prime moves)
- Auto scramble & solve
- Finger gesture control via webcam (TensorFlow.js HandPose)
- 6 UI themes
- Timer, move history, achievements

## Play
Open `index.html` or visit the GitHub Pages link.

## Gesture Control
- Point index finger at camera
- Swipe left/right → row moves (U / E / D layer)
- Swipe up/down → column moves (L / M / R layer)
- Finger position in 3×3 grid determines which row/column
